Real Time Detection of Microhematuria

Python C Data Structures and Algorithms Automated Systems

I automated the software pipeline from imaging of urine under a microscope to image detection using machine learning to quicken the diagnosis of microhematuria, the most common diagnosis in urology.

UTBiome Design Team @UofT

Overview

Microhematuria is the most common diagnosis in urology, but health clinics' ability to diagnose is limited by the requirement to send samples to a lab and wait for results. To solve this, I worked as part of a team to create a microscope that takes photos of samples and uses image detection software to determine if blood is present. The project aims to allow instant on-device red blood cell count for samples of urine so clinics can make efficient diagnoses. In my role, I programmed software for both a Raspberry Pi and a computer to make the pipeline from video capture to detection seamless.

Technical Approach

My technical approach to this project aimed to create a pipeline that was scalable, had little latency, and was intuitive to use. I did this by ensuring code runs using an efficient algorithm in terms of Big O Notation, reduced files to byte arrays which could be easily sent to a computer, and reduced the number of user inputs required to send files between computers. I am continuing to make the process more intuitive by adding an interface with buttons and automatically running the program using crontab.

Results & Impact

So far, I have automated the sending of files and improved the efficiency of the algorithm. As I continue to work on the project, I will create a better interface that is more automated so the product can be easily used by clinicians. Once the team has completed all of the different components of the product, we will present it to the Farcas Lab team so they can tweak and refine the product so it is ready for clinicians use.
